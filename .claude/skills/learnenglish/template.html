Note 07 · P0 milestones M1–M2

Building an LLM Gateway from Scratch

Core idea
  • Build a gateway only when configuration cannot do what you need, such as an exact budget cap.
  • Clients ask for a purpose (fast, smart). The alias maps to an ordered chain that ends with a local model.
  • Fall back only on transient errors: timeouts, 5xx and 429. A 400 means the request itself is wrong.
Try it

Input 1000 tokens, max_tokens 500, prices $0.20 and $0.60 per million. The answer uses 120 output tokens. How much is reserved, and how much is refunded?

reserve = 1000*0.20 + 500*0.60      # = 500 micro-USD, worst case
actual  = 1000*0.20 + 120*0.60      # = 272 micro-USD, real usage
refund  = reserve - actual          # = 228 micro-USD back to the budget
# keep money as integers (micro-USD): floats drift after millions of calls
Words from this note
fall back onphrasal verb

Use something else when the first option fails.
The gateway falls back on a local model when the cloud is down.

burn throughphrasal verb

Use up a resource quickly.
A bad loop can burn through your free quota in minutes.

hard capcompound noun

A limit that cannot be exceeded.
We set a hard cap of 1 USD per client.

transient failurecollocation

A temporary error that may disappear if you retry.
Retry only transient failures, such as timeouts.

runawayadjective

Out of control and growing fast.
A runaway loop caused the surprise bill.

at the cost ofphrase

Accepting a disadvantage to get a benefit.
You get more control at the cost of more maintenance.

Quick check
Why must the last link of every chain be a local model?

It keeps the service answering when every cloud provider is down or the quota is gone.

Why reserve first and settle after, instead of checking the balance?

The check and the update happen in one atomic step, so two concurrent requests cannot both pass.

Note 08 · P0 milestone M4

Semantic Caching Without False Hits

Core idea
  • Similarity measures topic closeness, not equal meaning. "National" and "international" fee questions can both score about 0.93.
  • Layer the defenses: namespace, search inside it, two calibrated thresholds, lexical guards, and a verifier for the gray zone.
  • Store only safe answers. When a source document changes, delete the entries that carry its tag. Never FLUSHDB.
Try it

Pairs are (similarity, same question?). You need 100% precision. Which threshold do you pick?

pairs = [(0.97, 1), (0.95, 1), (0.93, 0), (0.92, 1), (0.91, 0)]
# sorted high to low, precision stays 1.0 until 0.93 adds a false hit
# threshold = 0.95
# 0.93 is the "national" vs "international" fee pair: a similar score, a different answer
Words from this note
rule outphrasal verb

Decide that something is not possible or not right.
The lexical guards rule out hits where the numbers differ.

narrow downphrasal verb

Reduce many options to a smaller set.
The namespace narrows down the search to one context.

false positivecompound noun

A result marked as correct that is actually wrong.
A false positive here means a wrong cached answer.

gray zonecompound noun

An unclear area between two clear options.
Scores in the gray zone go to the verifier.

staleadjective

Old and no longer correct.
Tags remove stale answers when a document changes.

err on the side of cautionidiom

Choose the safer option when you are not sure.
Guards should err on the side of caution and reject doubtful hits.

Quick check
Why must the namespace filter be inside the KNN query?

A filter after KNN can remove all 5 neighbors, because they may belong to other namespaces. The result would be empty even when a valid entry exists.

Why use two thresholds instead of one?

Above the high one, guards are enough. Between the two, a verifier must agree. Below the low one, it is always a miss.

Note 09 · P0 milestones M3 and M6

Tail Latency and Overload Control

Core idea
  • Track p95 and p99, not the mean. A request makes several calls, so a rare slow call becomes a common slow request.
  • Hedge a late call to the next provider, adapt concurrency with AIMD on time to first token, and cap both so cost stays under control.
  • When overloaded, shed batch traffic first. Use singleflight for identical requests and token buckets for free-tier quotas.
Try it

Each call is slow 2% of the time and a request makes 3 calls. What share of requests is slow? Then, an AIMD limit of 10 sees a slow call: what is the new limit?

p, n = 0.02, 3
print(1 - (1 - p) ** n)   # 0.0588 -> about 5.9% of requests hit a slow call
limit = 10 * 0.7          # multiplicative decrease -> 7.0
Words from this note
ramp upphrasal verb

Increase gradually.
AIMD ramps up the limit slowly while latency stays healthy.

back offphrasal verb

Reduce activity to avoid overload.
Clients should back off when they receive a 429.

tail latencycompound noun

The slowest few percent of response times.
Hedging reduces tail latency.

load sheddingcompound noun

Rejecting some requests on purpose to protect the system.
Load shedding drops batch jobs before user requests.

stampedenoun

Many requests arriving at the same moment.
Singleflight prevents a stampede when a cache entry expires.

safety margincollocation

Extra space left to avoid reaching a limit.
Keep a 10% safety margin below the free-tier quota.

Quick check
Why hedge at the p95 and not earlier?

An earlier delay sends a second copy too often, which raises cost and load. At p95, only the slowest 5% of requests pay for a hedge.

Why use asyncio.shield in singleflight?

One waiting caller may be cancelled. Shield stops that cancellation from killing the shared call that other callers still need.
